# Tenify B2B Web

Standalone Next.js site for Tenify B2B. Current scope is a waitlist landing page.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Structure

- `app/` — App Router landing page
- `components/` — header, waitlist form, FAQ, screenshot placeholders
- `designs/` — Figma/design-tool export, design-system tokens, brand assets
- `docs/` — PRD, landing brief, messaging, pricing, brand guidelines

See `SCAFFOLDING.md` for what is still needed beyond this waitlist page.
