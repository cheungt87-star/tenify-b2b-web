Why This Combination?
Deep Navy provides professional trust and hierarchy. Bright Green offers energetic accents and modern brand distinctiveness. Together they achieve 14.2:1 contrast (highest possible) while maintaining warmth and approachability.

Standards

  • WCAG 2.1 Level AA compliant
  • AAA (best practice) where possible
  • Focus rings always visible
  • Color never sole indicator
  • Minimum 48px touch targets
  • Full keyboard navigation

Color-Only Rule

Information must NEVER be conveyed by color alone. Always pair with:

Status Color Icon Text Label
Completed ✓ ✓ Checkmark "Completed"
In Progress ⟳ ⟳ Spinner "In Progress"
Error ✕ ✕ Alert Error message

📋 Usage Guidelines

✅ Do's

  • Use Deep Navy for primary text and buttons
  • Use Bright Green for interactive focus states
  • Always include focus indicators on interactive elements
  • Pair status colors with icons and text
  • Test color combinations for contrast ratio
  • Use CSS variables; never hardcode colors

❌ Don'ts

  • ✕ Don't use Bright Green for primary text (too light)
  • ✕ Don't use navy for accents (blends into background)
  • ✕ Don't convey status by color alone
  • ✕ Don't hardcode hex values in components

CSS Variables

/* Use in your components */
--color-teal-900: #0F1F2E;    /* Deep Navy */
--color-ice-glass: #9fe870;   /* Bright Green */
--color-success: #3F7D53;
--color-error: #C84040;
--color-neutral-*: [grays]

⚙️ Implementation

All 20 components automatically inherit the new palette via CSS variables defined in src/index.css. No manual component changes needed.
